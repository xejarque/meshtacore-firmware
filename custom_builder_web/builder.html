Conexión MQTT Comunitaria

Habilitar Conexión MQTT de Fábrica

Conecta automáticamente con el broker comunitario de España (mqtt.meshtastic.es) cuando el nodo dispone de conexión a Internet (WiFi o pasarela).

⚠️ Esta placa no tiene red propia (WiFi/Ethernet): el MQTT solo funciona con «Proxy MQTT vía teléfono» activado.
Proxy MQTT vía teléfono (BLE)

Usa la conexión a Internet del móvil en lugar de WiFi o Ethernet. Necesario en placas sin red propia (nRF52 como la T1000-E); requiere la app oficial conectada por BLE.

🚀 Compilar con tu cuenta de GitHub

Recomendado • Sin necesidad de tokens

Cualquier usuario de GitHub puede solicitar su compilación a medida. Al pulsar el botón, se generará una solicitud oficial en GitHub con tu configuración.

Un bot de GitHub Actions compilará tu placa en ~2 minutos, aplicará un límite de protección (6 compilaciones al día por usuario) y te responderá en el hilo con el enlace de descarga directa del archivo ZIP listo para flashear.

Opciones alternativas

También puedes descargar el archivo de configuración para compilar tú mismo en local con PlatformIO, o disparar directamente vía API si dispones de un token personal.
