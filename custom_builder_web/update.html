🔄 Actualizar una placa

Instala un firmware nuevo en una placa que ya funciona con Meshtastic sin perder su configuración (canales, LoRa, nombre). Solo se reescribe la aplicación. Necesita Chrome o Edge de escritorio y la placa por USB.

Última versión publicada: —

Ojo con las builds personalizadas. Esto instala la build estándar de la comunidad. Si tu nodo se compiló con el builder, se pierden los módulos que excluiste y las opciones que compilaste. Tu configuración guardada sí se conserva. Para actualizar una build propia usa la pestaña «Mi build».

El .zip.enc o .zip que generó el builder, o un firmware-….bin suelto. Se usa su .bin de aplicación, no el .factory.bin, para conservar tu configuración.
