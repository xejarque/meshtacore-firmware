⚡ Flasher web

Flashea por USB, desde el navegador, un firmware que ya tienes: el que generó el Web Builder (ESP32 o nRF52). Todo ocurre en tu equipo: el firmware no se sube a ningún sitio. Necesita Chrome o Edge de escritorio. En las placas ESP32 escribe también el OTA Loader, para poder actualizar después por Bluetooth.

¿Quieres la versión estándar de la última release, o actualizar una placa conservando su configuración? Usa Instalar / Actualizar.

Opción A · Un archivo que ya tienes

El .zip.enc o .zip que descargaste de GitHub Actions, o un *.factory.bin suelto.

Opción B · Una compilación de GitHub Actions

Descarga el firmware directamente. Necesita un token con permiso de lectura de Actions (el mismo del builder).
