⚡ Instalar un archivo en mi placa

Aquí instalas por USB un firmware que ya tienes como archivo: por ejemplo el que descargaste después de usar Crear mi firmware. Todo ocurre en tu ordenador: el archivo no se sube a ningún sitio.

  1. Usa Google Chrome o Microsoft Edge en un ordenador y conecta la placa con un cable USB de datos.
  2. Pulsa «Elegir archivo» y selecciona el firmware.
  3. Cuando el navegador te pida un puerto, elige el de tu placa (suele llamarse USB, CP210x o CH340).
  4. Espera a que ponga «Terminado» sin desconectar el cable.

¿Solo quieres la última versión oficial, conservando tu configuración? Es más fácil en Instalar / Actualizar.

La placa no responde: cómo ponerla en modo instalación
  1. Placas ESP32 (Heltec, T-Beam, Station…): mantén pulsado el botón BOOT (o PRG), pulsa una vez RESET, suelta BOOT y vuelve a intentarlo.
  2. Placas nRF52 (RAK4631, T114, T-Echo, T1000-E…): pulsa dos veces seguidas y rápido el botón RESET. Aparecerá una unidad USB nueva.
  3. Si sigue sin funcionar, prueba otro cable USB y otro puerto del ordenador.

Elegir archivo

Vale el archivo que te dio el descargador (.zip.enc o .zip) o un *.factory.bin suelto.

Avanzado (colaboradores): descargar una compilación de GitHub Actions

Descarga el firmware directamente. Necesita un token con permiso de lectura de Actions (el mismo del builder).
