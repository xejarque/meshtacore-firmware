⚡ Flasher web

Flashea una placa ESP32 desde el navegador, sin instalar nada. Todo ocurre en tu equipo: el firmware no se sube a ningún sitio. Necesita Chrome o Edge de escritorio.

Opción A · Un archivo que ya tienes

El .zip.enc o .zip que descargaste de GitHub Actions, o un *.factory.bin suelto.

Opción B · Una compilación de GitHub Actions

Descarga el firmware directamente. Necesita un token con permiso de lectura de Actions (el mismo del builder).
